СЮДА КЛАДИ СВОИ ВИДЕО ДЛЯ ФОНОВ ОБЛОЖЕК (для тупых):

1. Положи сюда файл .mp4 (например, moon.mp4). Чем меньше вес — тем лучше,
   постарайся до 5-10 МБ: короткое видео по кругу смотрится так же, а грузится быстро.
2. Открой content/pages.json, найди нужную страницу и впиши имя файла:
   "cover_video": "moon.mp4"
3. Запусти python3 build.py, закоммить и запушь.

Такое видео грузится ВСЕГДА (не зависит от YouTube) и играет фоном без звука.
Если cover_video пустое ("") — фоном будет картинка cover_image,
а ролик с YouTube откроется только по кнопке ▶.
