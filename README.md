# Пакт крови — сайт фракции демонов

Полная копия сайта **https://bloodpact-yufu.tilda.ws/** (11 страниц), собранная заново в обычный HTML
в том же оформлении: чёрный фон, белый текст, статичные обложки с затемнением,
линии-разделители. Видеоплееры с обложек удалены. Адреса страниц те же, что были на Tilda: `/law/`, `/squads/`, `/ranking/` …

**Рабочий адрес: https://bloodpact.su/**

Хостинг — **GitHub Pages** (бесплатно): публикуется корень ветки `main` этого репозитория,
домен `bloodpact.su` подключён (файл `CNAME` в корне), HTTPS включён и принудителен.
Каждый коммит в `main` публикуется автоматически через 1–2 минуты.

Сайт переехал из репозитория [DeusOfSanguis/bloodpact](https://github.com/DeusOfSanguis/bloodpact):
раньше Pages публиковал папку `docs/` по адресу `deusofsanguis.github.io/bloodpact/`, теперь —
корень этого репозитория по адресу `bloodpact.su`. Старый репозиторий остаётся как архив исходников.

## Правки без кода (админка)

**Самый простой способ править часто меняющиеся списки — страница [`/admin/`](https://bloodpact.su/admin/)**
(не видна в меню, адрес нужно знать). Админка работает через GitHub: вход по
[Personal Access Token](https://github.com/settings/personal-access-tokens/new?name=bloodpact-admin&permissions=contents:read_write)
(Fine-grained → Repository access: только `DeusOfSanguis/bloodpact-site` → Permissions → Contents: **Read and write**).
Токен хранится только в браузере админа. Поле «Ветка» на входе — обычно **main**;
для тестов можно указать другую ветку (или `?branch=имя-ветки` в адресе).

Что можно менять прямо на сайте (вкладки админки):

| Вкладка | Что правит | Файл |
|---|---|---|
| **Отряды** | Группы и карточки отрядов: состав, владельцы, смотрящие, описание, задачи | `content/data/squads.json` |
| **Рейтинг** | Чемпион и таблица мест | `content/data/ranking.json` |

| **Шрамы** | Достижения и критерии повышения безотрядных по рангам (блочный + HTML редактор) | `content/scars.html` |

**Только админ:** запись идёт через GitHub API — изменения может сделать только человек с доступом
на запись к репозиторию. Обычные посетители ничего не изменят даже по адресу `/admin/`.
После «Сохранить» GitHub Actions сам пересобирает сайт (`.github/workflows/build-site.yml`),
и правки появляются на **https://bloodpact.su/** через 1–2 минуты.

Дальше — как добавить новые редактируемые списки или вкладку с текстом страницы:
выносите данные в `content/data/*.json`, рендерите их в `build.py` через плейсхолдер
(например `{{squads}}`) и добавляйте форму в `admin/index.html`. Архитектура рассчитана
на то, чтобы такие вкладки добавлялись без переделки остального.

## Как править тексты

По умолчанию тексты правьте **в админке `/admin/`** (см. выше). Если удобнее руками —
правьте файлы в `content/` (обычный HTML), затем:

```bash
python3 build.py                  # пересоберёт сайт в корень репозитория
git add -A && git commit -m "Правки" && git push origin main
```

Заголовки и изображения обложек, цитаты, порядок меню и домен — в `content/pages.json`.
Бегущая строка с цитатами демонов (Луны и Прародитель) — там же, в `content/pages.json` → `quotes` → `marquee`
(список пар `text` + `author`: строки можно добавлять, убирать и менять местами).
Посмотреть локально: `python3 -m http.server 8000` из корня репозитория → http://localhost:8000/

> ⚠️ `build.py` пишет готовый сайт прямо в корень, но удаляет только свои артефакты
> (`index.html`, `404.html`, `embed/`, каталоги страниц). `CNAME`, `.nojekyll`, `assets/img/`,
> `content/`, `scripts/` и сам `build.py` сборка не трогает.

Можно и без Python: править `*/index.html` напрямую в веб-редакторе GitHub — но тогда правки надо
дублировать в `content/`, иначе следующая сборка их перезапишет.

## Домен bloodpact.su

DNS у регистратора (уже настроено):

| Тип | Имя (хост) | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `deusofsanguis.github.io` |

Домен продублирован в `content/pages.json → "site" → "domain": "bloodpact.su"`, поэтому сборка
сама пересоздаёт `CNAME` — при пересборке он не теряется.

⚠️ **Не удаляйте `CNAME` и не меняйте поле Custom domain в Settings → Pages**, пока не готов
другой домен: Pages мгновенно начнёт переадресовывать на него все адреса, а без готового
HTTPS-сертификата сайт «ляжет» (404 / небезопасный http, встроенные ресурсы могут блокироваться браузером).

**Быстрый откат, если с доменом беда:** удалить `CNAME` из `main` и очистить поле
**Settings → Pages → Custom domain** — через 1–2 минуты сайт вернётся на
`deusofsanguis.github.io/bloodpact-site/`.

## Картинки

Фоновые изображения (`blood-moon.jpg` и `cover.jpg`) и карты территорий лежат локально в `assets/img/`.
Сайт не загружает портреты персонажей: вместо них используются графические печати и орнаменты.
Если понадобится перекачать старые:

```bash
python3 scripts/fetch_assets.py   # скачает файлы в assets/img/
python3 build.py                  # пересоберёт сайт с локальными картинками
```

## Обложки

Обложки всегда используют статичные изображения из `assets/img/` (`cover_image` в `content/pages.json`).
Кнопки включения YouTube-видео и фоновое видео отключены; блоки и цитаты персонажей не зависят от внешних видеосервисов.
Чтобы изменить обложку, укажи имя изображения в `cover_image` и пересобери сайт.

## Если всё-таки понадобится Google Sites

Google Sites не умеет импортировать готовый сайт (ни HTML, ни ZIP). Возможна только
**Вставка → Встроить → По URL** (адрес страницы без меню, например
`https://bloodpact.su/embed/law.html`): страница показывается в рамке с прокруткой.
Для «нативного» сайта на Google Sites текст удобно копировать прямо со страниц сайта,
открытых в браузере (жирный шрифт и списки сохраняются).

## Что отличается от Tilda

- Шрифт: вместо фирменного Tilda Sans — Inter (Google Fonts) с системным запасным шрифтом.
- Нет плашки «Made on Tilda».
- Обложки статичные: видеоплеера нет.
- Основные тексты сохранены; цитаты — реплики Прародителя и Двенадцати лун.
- Раздел «01 Демоны»: определение вида текстом и четыре свойства демона карточками — без повторов между ними.
- Название фракции `yufu` стоит только в подвале сайта (`content/pages.json → site.short`), в шапках страниц его нет.
- Кнопки «Познать тьму» и «Иерархия» с обложки главной удалены (герой собирается в `build.py → render_hero`).
- Экран загрузки главной: надписи «Возгордись / своей расой, своей кровью» показываются один раз за сеанс
  (`sessionStorage`, класс `bp-seen` на `<html>`), дальше переходы между страницами идут только со шторкой —
  две анимации подряд не накладываются. Правится в `build.py → render_preloader` и `content/theme.css`.
- Со внутренних обложек убран суффикс «· свиток» (было `法 Пакт крови · свиток`, стало `法 Пакт крови`).
