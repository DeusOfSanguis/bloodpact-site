Вход через GitHub

Админка работает через GitHub: изменения сохраняются в репозиторий, а сайт пересобирается автоматически. Право на изменения есть только у тех, у кого есть доступ на запись к репозиторию — это и есть проверка «только админ».

Обычно main — в неё пишутся правки и её публикует GitHub Pages. Для тестов до слияния можно указать другую ветку (например, ветку PR) — или добавить ?branch=имя-ветки к адресу страницы.
Токен нужен один раз и хранится только в вашем браузере (localStorage), никуда больше не отправляется, кроме api.github.com.
Как создать: Fine-grained token → Repository access: только DeusOfSanguis/bloodpact-site → Permissions → Contents: Read and write. Альтернатива: классический токен со scope repo.
