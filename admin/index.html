Вход через GitHub

Админка работает через GitHub API: изменения сохраняются прямо в репозиторий, а сайт пересобирается автоматически. Право на изменения есть только у тех, у кого есть доступ на запись к репозиторию.

Обычно main — в неё пишутся правки и её публикует GitHub Pages.
Токен хранится только в вашем браузере (localStorage) и не передаётся третьим лицам.
Как создать: Fine-grained token → Repository access: только DeusOfSanguis/bloodpact-site → Permissions → Contents: Read and write.
